`Donation.supportTier` LV1〜5 に 1 対 1 で対応する公式マスコットの透過 PNG。

- `512/` … 512×512 の正方形キャンバス（高さ 460 に揃え中央配置）。**アプリで使うのはこちら**
- `native/` … 切り出したままの等倍（193〜356px）。再加工用
- `preview_white.png` / `preview_navy.png` … 白地・濃紺地での見え方（目視確認用）

## 作り方（2026-09-22）
元画像は `ゼニくるマスコット.png`（進化図・1376×768。AI 生成、キャラは 1 枚に 5 体）。
1. 5 体を矩形で切り出し
2. 背景除去は rembg（LV2〜4 は `u2net`、LV5 は `isnet-general-use`。LV1 は旗の腕がモデルで消えるため、
   縁から推定した背景グラデとの色差キーイングを併用）
3. 最大の連結成分だけ残す（LV5 は光輪が離れているので 300px 以上の成分を残す）。背景の光彩・星は落とした
4. 白地・濃紺地で目視。内部透過は腕と体の隙間・光輪の内側のみ

## 注意
- **元画像の解像度が低く、512 化で約 1.5〜2.2 倍に拡大している。** 旗の柄など細い部分に薄い縁が残る。
  本番品質にするなら 1 体ずつ高解像度で生成し直すか、元の生成データを使う
- 進化図の英語表記「Fun」は「Fan」の誤り。文字は素材に含めていない
