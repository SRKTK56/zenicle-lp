# app.zenicle.jp を zenicle.jp のトンマナに揃える — 仕様書

対象: tmkn-jp/zenicle `apps/web`（公開ページ・チームコンソール）
基準: https://zenicle.jp （実装 `index.html`）と本ディレクトリのモック
作成: 2026-09-14

---

## 0. 現状診断（コードを読んだ結果）

| 領域 | 現状 | 判定 |
|---|---|---|
| カラートークン（公開ページ） | `globals.css` の `--c-*` / `--zen-*-rgb` はすでに LP と同じ「確定パレット 2026-07-22」（`#F7F9FC` / `#14213D` / `255 138 0`） | **ほぼ揃っている** |
| フォント | 両方 Noto Sans JP | 揃っている |
| **チームコンソール** `(team)/team/console/*` | `bg-zen-void` `text-white` `text-zinc-400` `bg-zen-bgCard` など**旧ダークテーマがハードコード**。トークンを通っていない | **最大のギャップ** |
| `ui/Button` | `primary` が `bg-blue-600`、`zen` variant はダーク前提（`text-[#0a0812]`、`ring-offset-[#0a0812]`） | 要修正 |
| `ui/Card` ほか共通部品 | ダーク用の `border-zen-line` / `bg-zen-bgCard` を参照する箇所が残る | 要修正 |
| 角丸・影 | LP: カード `1.25rem`、ボタン `999px`、影 `0 10px 30px rgba(20,33,61,.08)`。アプリ: `rounded-[10px]`、`shadow-zen-glow-*`（発光系） | 統一する |
| チームページ `/t/[id]` | セクション順・見出しが LP の導線と不一致（後述） | 再設計（モックあり） |

結論: **「色を変える」仕事ではなく、「コンソールをライトテーマのトークンに乗せ、共通部品の見た目を LP に合わせる」仕事**。

## 1. トークン対応表

LP の `:root`（`index.html`）と、アプリ `globals.css` の用途別トークンの対応。
値が違う行だけアプリ側を LP に合わせる（★印）。

| 役割 | LP（正） | アプリ現行 | 対応 |
|---|---|---|---|
| ページ背景 | `--bg: #F7F9FC` | `--c-bg-base: #f7f9fc` | 同じ |
| 帯・カード背景 | `--bg-band: #FFFFFF` | `--c-bg-alt` / `--c-bg-card: #ffffff` | 同じ |
| 薄い面 | `--surface-soft: #F4F7FC` | `--c-bg-surface: rgba(20,33,61,.04)` | ほぼ同じ（どちらでも可） |
| 本文 | `--text: #14213D` | `--c-text-body: #14213d` | 同じ |
| 補足文 | `--text-muted: #5B6473` | `--c-text-muted: #374151` | ★ `#5B6473` に |
| 注釈 | `--text-subtle: #8A93A3` | `--c-text-subtle: #6b7280` | ★ `#8A93A3` に |
| 罫線 | `--border: rgba(20,33,61,.10)` | `--c-border-line: rgba(20,33,61,.12)` | ★ `.10` に |
| 強い罫線 | `--border-strong: rgba(20,33,61,.14)` | `--c-border-strong: rgba(20,33,61,.22)` | ★ `.14` に |
| 主役色 | `--brand: #FF8A00` | `--zen-orange-rgb: 255 138 0` | 同じ |
| アクセント | `--pink: #FF4D8D` | `--zen-pink-rgb: 255 77 141` | 同じ（達成率・CUPにだけ使う） |
| 主役グラデ | `linear-gradient(135deg,#FFA726,#FF8A00)` | `--c-grad-orange-from/to` | 同じ |
| 文字グラデ | `linear-gradient(135deg,#FF8A00,#FF4D8D)` | なし | ★ 追加（`--c-grad-text`）。数値・強調語にだけ使う |
| カード影 | `0 10px 30px rgba(20,33,61,.08)` | `shadow-zen-glow-*`（発光） | ★ 追加 `--c-shadow-card`。発光系は使わない |
| ホバー影 | `0 18px 44px rgba(20,33,61,.14)` | なし | ★ 追加 `--c-shadow-card-hover` |
| ボタン影 | `0 10px 30px rgba(255,138,0,.28)` | `0 12px 50px rgba(245,158,11,.45)` | ★ 値を差し替え |
| フッター | `--footer-bg: #14213D` | — | ネイビー地・白文字（LP と同じ） |

**ダークテーマ（`data-theme='dark'`）は当面「維持だけ」**。新規の見た目調整はライトだけで行い、ダークは壊れていなければ触らない。

## 3. チームコンソール（`(team)/team/console`）

### 3.1 テーマ
- `bg-zen-void` / `bg-zen-bgCard` / `bg-zen-bgOverlayDark` / `text-white` / `text-zinc-*` / `hover:bg-white/5` を**すべて `--c-*` トークンに置換**し、ライトテーマにする（公開ページと同じ地）
- サイドバー: 白地、選択中は `bg-orange-500/10 text-orange-600 font-bold`、それ以外は `--c-text-muted`
- ヘッダー: 白地・下罫線 `border-line`。「チームコンソール」の h1 はネイビー

### 3.2 情報設計 — ページの構造 = 編集の構造
困りごと: **「どこを編集すれば公開ページのどこに出るか」が分からない。**
対策は3つ。順に効く。

1. **サイドバーを公開ページのセクション名・順番と完全に一致させる**（下表）
2. **各編集画面の冒頭に「チームページの『○○』に表示されます」＋そのセクションのプレビュー画像（縮小スクショで可）**を置く
3. **公開ページにメンバー限定の「✎ 編集」導線**を出す（モック `team.html?edit=1` の青いチップ）。クリックで該当コンソール画面へ

### 3.3 ページ ↔ 編集画面 対応表（サイドバーの順番そのもの）

| # | 公開チームページのセクション | コンソールのメニュー名 | 編集項目 | 現在の置き場 |
|---|---|---|---|---|
| — | カバー画像・チーム名 | **ヘッダー** | iconUrl（21:9）、name | 設定「表示・公開」 |
| 01 | プロジェクト説明動画 | **プロジェクト** | pitchVideoUrl、goalAmount | 設定「プロジェクト」（新設済） |
| 応援 | 累計・目標・達成率・応援ボタン・シェア | （自動） | 表示のみ。目標額は「プロジェクト」で | — |
| 02 | 活動紹介・メッセージ | **活動紹介** | description、thanksMessage【要確認: 公開APIに未提供】 | 設定「表示・公開」／シーズン設定 |
| 03 | メンバー紹介 | **メンバー** | メンバー、役割、プロフィール（avatar/bio） | メンバー |
| 04 | エールの使い道 | **使い道（支出）** | fundUsage | 支出 |
| 05 | 応援してくれている人 | （自動） | 表示のみ | — |
| 06 | 活動レポート | **活動レポート（投稿）** | progressPosts、支援者限定 reports | 投稿／レポート |
| 末尾 | SNS リンク | **SNS** | webUrl / xUrl / instagramUrl / youtubeUrl / otherUrl | 設定「SNS」 |
| — | 公開設定・誓約 | **公開設定** | status、コンプライアンス | 設定「表示・公開」「コンプライアンス」 |

「（自動）」の項目もサイドバーに**読み取り専用で並べる**（「自動で表示されます」と書く）。編集できないことを隠すと、探し続けてしまう。

### 3.4 コンソールトップ（`/team/console`）
「やること」を上に、「数字」を下に。
- 上段: 未完了の設定をチェックリストで（動画URL未登録／目標額未設定／使い道の登録が0件／今週の投稿なし）。各行から該当画面へ
- 中段: 公開ページの縮小プレビュー（iframe で `/t/<id>` を表示。編集後すぐ確認できる）
- 下段: 累計・応援者数・シーズン残日数

## 4. チームページ `/t/[teamId]` — モック `team.html`

- 実装の正: `design/team.html`（実 API で描画。`?team=<id>` で任意チーム、`&edit=1` でメンバー表示）
- セクション順（確定）: **カバー → 01 動画 → 応援（目標・累計・達成率・応援ボタン・X/Threads/LINE/URLコピー） → 02 活動紹介・メッセージ → 03 メンバー → 04 使い道 → 05 応援者 → 06 活動レポート**
- PC: 本文 8 カラム＋右 4 カラムの応援レール（sticky）。スマホ: 動画の直後に応援ブロック、画面下に固定 CTA バー
- 空状態は「まだ登録されていません。登録すると○○が表示されます」と、次の行動が分かる文にする
- 数値の色: 累計額だけ `gold-text`、達成率だけピンク。それ以外はネイビー
- 【要確認】: thanksMessage の公開 API 提供、支援者限定レポートの件数表示

## 5. 進め方（PR の切り方）

1. **PR-1 トークン＆共通部品**（§1・§2）: 公開ページ全体が LP のトーンになる。差分は CSS とコンポーネントのみ
2. **PR-2 コンソールのライト化**（§3.1）: 見た目だけ。導線は変えない
3. **PR-3 チームページ再設計**（§4）: モックの構造に置き換え。`?edit=1` 相当のメンバー用「✎ 編集」も同時に
4. **PR-4 コンソールの情報設計**（§3.2〜3.4）: サイドバー並び替え・各画面の冒頭案内・トップの「やること」

各 PR の受け入れ基準は「zenicle.jp と並べて違和感がないこと」＋「対応表どおりに編集先へ辿れること」。
